# 💰 Expense Tracker

A modern and responsive **Expense Tracker** built using **HTML, CSS, and JavaScript**. Track your income and expenses, monitor your balance in real-time, and manage your transactions through a clean and intuitive user interface.

---

## 🚀 Features

- 💵 Track income and expenses
- 📊 Real-time balance calculation
- ➕ Add new transactions
- 🗑️ Delete transactions
- 📈 Automatic income & expense summary
- 🎨 Modern UI with gradient finance-themed design
- 📱 Responsive layout
- 💾 Data persistence using Local Storage

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

## ⚙️ How It Works

1. Enter a transaction description.
2. Enter an amount:
   - Positive value ➜ Income
   - Negative value ➜ Expense
3. Click **Add Transaction**.
4. The application automatically:
   - Updates total balance
   - Updates income summary
   - Updates expense summary
   - Stores data in Local Storage
